# Documentary scenarios and traceability

Review date 2026-11-02. These are **paper executions of proposed contracts**, not code or runtime results. COHERENT means the specified initial state, transitions and expected outcome agree; BLOCKED means a required path has an identified ARH gap; UNRESOLVED means consumer feasibility/authority must be established. A coherent refusal may be an intentional safe result. All ARH labels here are symbolic references in textual fixtures, never claims of committed real records.

The integrated product journey is [W-2](desk-walkthrough.md). Its nine successive snapshots combine the isolated cases here without pretending runtime validation. W-2's stipulations and account scope are distinct from W-1, S-15 and V-01; no totals are merged across fixtures.

Common fixture: M-1/ES-M1 in [C-01–C-03](contracts.md), cooperative local identities R-T, R-R, CK, owner O; one ARH run ARH-X; shared researcher grant G-R=10.00, Checker G-C=2.00; all operations have durable distinct keys and frozen hashes. All scenarios assume proposed authority for paper reasoning only. Each row's resulting state follows only the stated records; no unstated agent memory is available. Cases are independent except named W-1 continuation.
